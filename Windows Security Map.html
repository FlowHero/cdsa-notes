Kerberoasting → Silver Ticket: Crack the TGS → get plaintext → derive NTLM hash → forge TGS for that service as any user. Choose Silver Ticket (Kerberos, no DC logs, single service) or Pass-the-Hash (NTLM, broader but leaves EID 4624 LogonType=9).
LSASS Dump → three roads: Got a hash? → PtH (NTLM lateral) or Overpass-the-Hash (Kerberos lateral, stealthier, Rubeus port 88 IoC). Got a TGT? → Pass-the-Ticket directly — no cracking needed.
Unconstrained Delegation → Golden Ticket: Compromise a UD server → coerce DC to authenticate → steal DC's TGT from LSASS → PtT as DC → DCSync → KRBTGT hash → Golden Ticket. Full domain persistence achieved without ever brute-forcing a password.

Detection Tool Layers
Sysmon

Microsoft Sysinternals driver + service. Fills gaps in Security log.

EID 1Process Create (parent-child, cmdline)
EID 3Network Connection (C2, OtH port 88)
EID 7Image Loaded (DLL hijack, .NET inject)
EID 10Process Access (LSASS dump)
EID 22DNS Query (LLMNR honeypot hits)
Install: sysmon.exe -i -accepteula -h md5,sha256,imphash -l -n
