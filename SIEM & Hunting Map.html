Threat Hunting Frameworks
Pyramid of Pain
Higher = more painful for attacker to change = better detection value
TTPs
Tactics, Techniques, Procedures
Tools
Malware, scripts, custom binaries
Network / Host Artifacts
Logs, registry keys, file paths, memory
Domain Names
DGA / dynamic DNS – moderately easy to change
IP Addresses
VPN / proxy / TOR – easy to rotate
Hash Values
MD5 / SHA1 / SHA256 – trivial to recompile
Key insight: Detecting at TTP level forces adversary to fundamentally change their behaviour. Hash-only detection is trivially bypassed.
Diamond Model of Intrusion Analysis
Four vertices; an event links all four
⚔
Adversary
Who — cybercriminals, insiders, APTs, state actors
⚙
Capability
What — malware, exploits, custom tools, TTPs
🖧
Infrastructure
Where — C2 servers, IPs, domains, botnets
🎯
Victim
Who hit — org, system, person, data asset
IOC Types & Detection Value
File Hashes MD5, SHA-1, SHA-256 — exact match Low value
IP Addresses C2 IPs, scan sources — easily rotated Low-Med
Domain Names DGA domains, fast-flux — moderate Medium
Artifacts Registry keys, file paths, log patterns High
TTPs Behavioural patterns — hardest to change Highest
